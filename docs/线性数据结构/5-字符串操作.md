在算法面试中，字符串处理的 API 熟练度直接决定了你的编码速度。字符串在大多数语言中是**不可变（Immutable）**的，这意味着几乎所有的“修改”操作都会产生新字符串。

以下是脱离语言的抽象函数清单，以及 Go 和 Python 的具体实现对比。

---

## 1. 字符串基础操作清单 (Language-Agnostic)

无论使用什么语言，你必须掌握以下六类基本操作：

1. **查找与匹配**：`Contains` (是否存在), `Index` (第一个出现位置), `StartsWith`/`EndsWith` (前后缀)。
2. **转换/修改**：`Replace` (替换), `ToLower`/`ToUpper` (大小写), `Trim` (去空格/指定字符)。
3. **切分与合并**：`Split` (按分隔符切开), `Join` (将集合合并为字符串)。
4. **子串提取**：`Substring` (截取一段长度或区间)。
5. **类型转换**：`String <-> Integer/Float`, `String <-> Char Array/Byte Slice`。
6. **特殊操作**：`Reverse` (反转)。

## 2. Python vs. Go 实现对比

### A. 常用工具函数对照表

| 功能 | Python (内置/str 方法) | Go (`strings` / `strconv` 包) |
| --- | --- | --- |
| **长度** | `len(s)` | `len(s)` (字节长度) / `utf8.RuneCountInString` |
| **包含** | `"a" in s` | `strings.Contains(s, "a")` |
| **位置** | `s.find("a")` / `s.index()` | `strings.Index(s, "a")` |
| **前后缀** | `s.startswith("pre")` | `strings.HasPrefix(s, "pre")` |
| **替换** | `s.replace("a", "b", n)` | `strings.Replace(s, "a", "b", n)` |
| **分割** | `s.split(",")` | `strings.Split(s, ",")` |
| **拼接** | `",".join(list)` | `strings.Join(slice, ",")` |
| **大小写** | `s.lower()` / `s.upper()` | `strings.ToLower(s)` / `strings.ToUpper(s)` |
| **去首尾** | `s.strip()` | `strings.TrimSpace(s)` / `strings.Trim()` |

### B. 进阶/特殊操作 (面试高频)

#### 1. 子串截取 (Slicing)

* **Python**: `s[start:end]` (非常强大，支持负数索引 `s[:-1]`)。
* **Go**: `s[start:end]` (基于字节。如果是中文字符串，直接截取会乱码，需先转为 `[]rune`)。

#### 2. 字符串反转 (Reverse)

* **Python**: `s[::-1]` (切片魔法，一行搞定)。
* **Go**: **无内置函数**。必须手动实现（通常先转为 `[]rune` 或 `[]byte`，再用双指针交换）。

#### 3. 数值转换 (Conversion)

* **Python**: `int("123")` / `str(123)`。
* **Go**: `strconv.Atoi("123")` / `strconv.Itoa(123)`。

## 3. 语言特性避坑 (社招复习重点)

### Python：简洁但有开销

* **频繁拼接**：在循环内 `s += "a"` 是 。面试中如果涉及大量拼接，应先存入列表 `res.append()`，最后执行 `"".join(res)`。
* **字符判断**：`c.isdigit()`, `c.isalpha()`, `c.isalnum()` 非常好用。

### Go：严谨但稍显繁琐

* **Byte vs Rune**：
* `s[i]` 得到的是 `byte` (uint8)。
* 遍历包含中文的字符串要用 `for _, r := range s`，此时 `r` 是 `rune` (int32)。


* **高性能拼接**：面试中如果被问及性能，提到 `strings.Builder` 会是加分项， 具有可动态扩容的缓冲区，而直接字符串拼接会涉及到开销问题。 
```go  
var sb strings.Builder
// 写入字符串
sb.WriteString("hello ")
// 写入单个字节
sb.WriteByte('w')
// 写入字节切片
sb.Write([]byte("orld"))
// 格式化写入
fmt.Fprintf(&sb, " %d", 2025)

// 最终生成字符串
s := sb.String()
fmt.Println(s) // hello world 2025
```


* **不可变性**：要修改字符串中的某个字符，必须先转成切片：`temp := []byte(s)` -> 修改 `temp[i]` -> `string(temp)`。
