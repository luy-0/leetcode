双指针（Two Pointers）是解决线性结构问题的核心技巧。在社招面试中，它往往是  暴力解法向  高效解法进阶的关键。

我们将双指针归纳为以下四大模式：

---

## 1. 左右指针（向中间靠拢）

主要用于**有序**数组或字符串，通过两个指针向中间收缩来寻找目标。

* **场景**：
* **二分查找**：最经典的左右指针应用。
* **两数之和（有序数组）**：根据 `sum` 与 `target` 的大小关系移动 `left` 或 `right`。
* **反转数组/字符串**：交换指针指向的元素。
* **盛最多水的容器/接雨水**：利用木桶效应，移动较短那一侧的指针。


* **核心逻辑**：
```python
left, right = 0, len(nums) - 1
while left < right:
    if condition: left += 1
    else: right -= 1

```



---

## 2. 快慢指针（同向移动）

主要用于处理**链表**问题，或者在数组上进行**原地修改**。

* **场景**：
* **判定环**：快指针走两步，慢指针走一步，相遇则有环。
* **寻找中点**：快慢指针同时出发，快指针到终点时，慢指针在中点。
* **寻找倒数第 K 个节点**：快指针先走 K 步，然后同步移动。
* **原地去重/移动元素**：慢指针指向“已处理序列”的尾部，快指针用于扫描。


* **核心逻辑**：
```python
slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow == fast: # 发现环
        break

```



---

## 3. 滑动窗口（变长/定长区间）

这是双指针的一种特殊形式，`left` 和 `right` 维护一个窗口，用于解决**连续子区间**问题。

* **场景**：
* **最长无重复子串**：`right` 扩张，出现重复时 `left` 收缩。
* **最小覆盖子串**：窗口满足要求后尝试收缩以获取最小值。


* **核心逻辑**：
```python
left = right = 0
while right < len(s):
    window.add(s[right]) # 扩大窗口
    right += 1
    while window_needs_shrink: # 满足收缩条件
        window.remove(s[left]) # 缩小窗口
        left += 1

```



---

## 4. 分离双指针（多路归并）

两个指针分别指向**两个不同的线性结构**。

* **场景**：
* **归并排序的合并过程**：比较 `ptr1` 和 `ptr2` 指向的值，小的入结果集。
* **求两个数组的交集/并集**。
* **判断子序列**：`s` 是否为 `t` 的子序列。


* **核心逻辑**：
```python
i, j = 0, 0
while i < len(A) and j < len(B):
    if A[i] < B[j]: i += 1
    else: j += 1

```

## 社招复习要点 (Review Notes)

1. **边界细节**：面试中 80% 的 Bug 都在于 `while left < right` 还是 `left <= right`，以及指针越界的判断。
2. **单调性**：使用左右指针的前提通常是数据具有**单调性**（有序）。
3. **状态维护**：滑动窗口最难的部分是随着指针移动，如何高效更新窗口内的统计状态（如使用 `HashMap`、`Counter` 或 `Sum`）。
4. **空间优化**：双指针往往能将  的空间复杂度优化到 （原地修改）。
