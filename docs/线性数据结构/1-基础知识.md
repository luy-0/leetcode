# 线性数据结构核心复习清单

## 1. 数组 (Array)

### 内存与性能

* **物理特性**：连续内存空间，支持随机访问（Random Access）。
* **复杂度**：读取 ，插入/删除 。
* **缓存友好性**：具备良好的空间局部性（CPU Cache Friendly）。

### 核心考点与技巧

* **双指针 (Two Pointers)**：
* 左右指针：处理有序数组（求和、反转）。
* 快慢指针：处理原地修改（去重、移动零）。


* **滑动窗口 (Sliding Window)**：处理子数组（Subarray）的最值、定长/变长问题。
* **前缀和 (Prefix Sum)**：解决频繁查询区间和的问题。
* **差分数组 (Difference Array)**：解决频繁批量修改区间值的问题。
* **二分搜索 (Binary Search)**：注意边界条件（左闭右开、左闭右闭）及变体（查找第一个/最后一个等值元素）。

---

## 2. 链表 (Linked List)

### 物理结构

* **物理特性**：非连续内存，通过指针（Pointer/Reference）连接。
* **复杂度**：查找 ，已知位置的插入/删除 。
* **变体**：单链表、双向链表、循环链表。

### 核心操作与模版

* **虚拟头节点 (Dummy Node)**：简化边界处理（如头节点被删除、新链表构建）。
* **快慢指针 (Fast/Slow Pointers)**：
* 寻找链表中点。
* 判断链表是否有环（Floyd's Cycle-Finding）。
* 寻找环的入点。
* 寻找倒数第 K 个节点。


* **基本变换**：
* 链表反转（迭代版 vs 递归版）。
* 局部反转（K 个一组反转）。
* 链表合并（Sorted Merge）。
* 链表划分（Partition List）。



---

## 3. 字符串 (String)

### 特性与存储

* **不可变性 (Immutability)**：在 Java/Python 等语言中需注意频繁拼接产生的开销（使用 StringBuilder/List）。
* **编码**：ASCII、UTF-8、Unicode 的区别。

### 核心算法与考点

* **回文判断 (Palindrome)**：中心扩散法、双指针法。
* **字符映射**：利用数组（size=26 或 256）代替 HashMap 进行字符频率统计。
* **子串搜索**：
* KMP 算法（前缀函数 `next` 数组）。
* 滑动窗口（处理最长无重复子串、异位词搜索）。


* **反转策略**：整体反转 + 局部反转（解决“翻转字符串中的单词”类问题）。
* **字典树 (Trie)**：处理前缀匹配、大量字符串存储与搜索。

## 4. 总结：线性结构通用备考模式

* **空间换时间**：利用哈希表将  查找降至 。
* **越界检查**：数组下标（`i < len`）、链表指针（`cur.next != null`）。
* **逆向思维**：从后往前处理数组以避免频繁移动元素。
* **原地修改 (In-place)**：面试官通常通过限制  空间复杂度来考察对指针操作的熟练度。
