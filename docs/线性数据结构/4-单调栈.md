单调栈（Monotonic Stack）是解决“**寻找下一个更大/更小元素**”这类问题的终极武器。在社招算法面试中，它是区分“只会暴力解”和“掌握进阶技巧”的重要分水岭。

---

## 1. 核心定义

单调栈本质上是一个栈，但它在入栈时会通过出栈操作，始终保持栈内元素的**单调性**（单调递增或单调递减）。

* **单调递增栈**（从栈底到栈顶）：用于寻找左/右第一个比当前元素**小**的元素。
* **单调递减栈**（从栈底到栈顶）：用于寻找左/右第一个比当前元素**大**的元素。

---

## 2. 核心应用场景

如果题目描述中包含以下关键词，应优先考虑单调栈：

* “左边第一个比它大的数”
* “右边第一个比它小的数”
* “寻找下一个更大元素 (Next Greater Element)”
* “计算以当前高度为最小值的最大区间”

---

## 3. 标准算法模板

以“寻找右侧第一个比当前元素大的数”为例：

```python
def nextGreaterElement(nums):
    res = [-1] * len(nums)
    stack = []  # 栈中通常存储索引，方便计算距离或填充结果数组

    for i in range(len(nums)):
        # 当栈不为空 且 当前元素大于栈顶元素时
        # 说明找到了栈顶元素的“下一个更大元素”
        while stack and nums[i] > nums[stack[-1]]:
            top_index = stack.pop()
            res[top_index] = nums[i]
        
        # 将当前索引入栈
        stack.append(i)
    
    return res

```

## 4. 关键技巧与细节

### A. 栈里存什么？

* **存索引（Index）**：强烈建议在面试中存索引而非数值。存索引既可以得到数值 `nums[i]`，又可以计算元素之间的**距离**（比如“接雨水”或“柱状图中的最大矩形”）。

### B. 三个关键动作

1. **比较**：当前元素与栈顶元素比较。
2. **出栈（Pop）**：满足破坏单调性的条件时出栈，并在此时更新答案。
3. **入栈（Push）**：当前元素在处理完前面的出栈后，必须入栈。

### C. 复杂度分析

* 虽然代码里有 `while` 嵌套在 `for` 循环中，但每个元素最多入栈一次、出栈一次。

## 5. 经典面试题回顾

1. **LeetCode 496 / 503 (Next Greater Element I & II)**：基础模板题。注意 II 是**循环数组**，常用技巧是将数组长度翻倍或取模 `i % n`。
2. **LeetCode 739 (Daily Temperatures)**：寻找右边第一个比当前大的数，计算距离。
3. **LeetCode 84 (Largest Rectangle in Histogram)**：
* **思路**：寻找每个柱子左右两侧第一个比它矮的柱子。
* **技巧**：在原数组两端加上“哨兵”（高度为 0），可以避免判空操作，代码极其简洁。


4. **LeetCode 42 (Trapping Rain Water)**：
* 除了双指针法，单调递减栈是另一种主流解法。当出现一个比栈顶大的元素时，形成凹槽，触发结算。

## 6. 社招避坑指南

* **注意严格单调 vs 非严格单调**：取决于题目是否允许处理相等的值（`>` 还是 `>=`）。
* **空间换时间**：单调栈是典型的用空间换取  时间的策略，面试官可能会追问在内存受限的情况下如何处理（此时可能考察双指针或分块思想）。
